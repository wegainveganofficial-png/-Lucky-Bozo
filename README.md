# Lucky Bozo · ลานหวยตัวตลก

เว็บแอปมือถือสไตล์สวนสนุก สำหรับดูสถิติเลข 3 ตัวของสลากกินแบ่งรัฐบาลย้อนหลัง 20 ปี

- **ผลรางวัล:** ผลงวดล่าสุด และเลือกดูย้อนหลัง 10 ปีได้ครบทุกรางวัล
- **สถิติ:** จัดอันดับเลข 3 ตัว 1–500 แยกตามประเภทรางวัล (3 ตัวบน / หน้า / ท้าย) ช่วงเวลา (20 / 10 / 5 ปี) และวันงวดของปี
- **วงล้อ:** หมุน 3 รอบได้เลข 3 ตัว เลือกได้ว่าจะถ่วงน้ำหนักตามสถิติของวันงวด หรือสุ่มเท่ากันทุกเลข

> ผลสลากเป็นการสุ่ม ทุกเลขมีโอกาสเท่ากันทุกงวด สถิติในแอปนี้ใช้เพื่อความบันเทิง ตรวจผลอย่างเป็นทางการได้ที่ https://www.glo.or.th

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด ฝังข้อมูลสำรอง 471 งวด (30 ธ.ค. 2549 – 16 ก.ย. 2569) |
| `config.js` | URL และ anon key ของ Supabase |
| `supabase/lotto_draws.sql` | สร้างตาราง `lotto_draws` ตั้ง RLS ให้อ่านได้อย่างเดียว และใส่ข้อมูลทั้งหมด |
| `scripts/build.py` | สร้าง `index.html` ใหม่จาก thai-lotto-archive |

## ตั้งค่า Supabase

1. เปิดโปรเจกต์ Supabase ไปที่ **SQL Editor** วางเนื้อหา `supabase/lotto_draws.sql` แล้วกด Run (รันซ้ำได้ ข้อมูลไม่ซ้ำ)
2. ไปที่ **Project Settings → API Keys** คัดลอก publishable / anon key มาใส่ใน `config.js` ตรง `supabaseAnonKey`
3. เมื่อมีผลงวดใหม่ ให้ insert แถวใหม่ลงตาราง `lotto_draws` แอปจะดึงข้อมูลใหม่เองโดยไม่ต้องแก้โค้ด

ถ้าดึงข้อมูลจาก Supabase ไม่สำเร็จ หรือยังไม่ได้ใส่ key แอปจะใช้ข้อมูลที่ฝังในไฟล์แทน ท้ายแท็บผลรางวัลจะบอกว่ากำลังใช้แหล่งข้อมูลไหนอยู่

## เปิดใช้ GitHub Pages

ไปที่ **Settings → Pages** เลือก Source เป็น `Deploy from a branch` เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
